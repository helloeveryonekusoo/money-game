# マネーゲーム

貸与された100万円を武器に読み合う、2人対戦の心理戦ゲーム。
ブラウザだけで動作します。対戦方法は2つ:

- **1台で対戦(ホットシート)**: 1台の端末を交互に使う。
- **オンライン対戦(2端末)**: 片方が「部屋を作る」で6桁コードを発行し、もう片方がコードを入力して参加。
  WebRTC(PeerJS)によるP2P通信で、サーバー設置は不要。

## 遊び方

GitHub Pages で公開されている URL をブラウザで開くだけ。インストール不要。
ローカルで遊ぶ場合は `index.html` をブラウザで開いてください(オンライン対戦はネット接続が必要)。

※オンライン対戦の通信はブラウザ間の直接通信(P2P)です。一部の携帯回線・社内ネットワークでは
接続できない場合があります。その場合は同じWi-Fiに繋ぐか、ホットシートでお楽しみください。

## ルール概要

- 各プレイヤーは **攻撃用現金100万円** と **防御用予想枠100万円** を持つ(どちらも使い切り)。
- 毎ゲーム同時進行: 箱に金を仕込む(3分) → 中身を宣言(嘘OK) → 相手の箱を予想(5分) → 一斉オープン → スキル判断(1分)。
- 確認画面(宣言公開・結果表示など)は15秒で自動的に次へ進む。
- 箱に入れられるのは **1ゲーム合計50万円まで**(最終ゲームは2箱合計)。残金・残り予想枠を超える入力はできない。
- 中身 > 予想 → 攻撃側が差額を勝ち点として獲得。
- 予想ぴったり → **ぴったり賞**: 防御側が中身と同額を獲得。
- 宣言が真実だった場合、その回の攻撃獲得は **20%アップ**(正直者ボーナス)。
- 全3ゲーム。最終ゲームは **ダブルボックス**: 箱2つに振り分け、相手は両方を予想する。
- 勝敗は勝ち点合計。同点なら残金勝負。**敗者にはお迎えが来る。**

## スキル(1試合に1回)

事前選択なし。使いたいタイミングで、その場で1つ選んで使用します。

| スキル | タイミング | 効果 |
|---|---|---|
| 倍プッシュ | 仕込み時 | この回の獲得2倍(宣言時に公開される) |
| 追加融資 | 仕込み時 | 現金+20万円 or 予想枠+20万円 |
| 査察官 | 予想時 | 「箱はN万円以上か?」を1回質問(回答は真実) |
| 差し押さえ | 予想時 | 防御成功なら差額を獲得 |
| 保険 | オープン後 | 相手のこの回の獲得を半減 |

## ファイル構成

```
index.html      … エントリポイント
css/style.css   … スタイル
js/game.js      … ゲームロジック + 通信(PeerJS)
ゲーム企画案.md  … 企画書
```

依存ライブラリ: [PeerJS](https://peerjs.com/)(オンライン対戦時のみ、CDNから読み込み)

※カジュアルゲームのため、通信はクライアント同士の信頼ベースです(チート対策なし)。
